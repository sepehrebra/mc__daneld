# وضعیت مهاجرت
- گام ۶: ایجاد و وضعیت دوره، برداشت، انتقال و حذف با تراکنش؛ محافظ تاریخ و ارجاعات دیگر اضافه شد.
- آزمون گام ۶: `python django_backend/manage.py test accounts farms config operations`؛ ۴۶ تست روی SQLite حافظه‌ای موفق.
- فرض/تصمیم: برداشت چند دورهٔ فعال، جدیدترین شروع واقعی و سپس بیشترین شناسه را می‌گیرد؛ انتقال کاشت برنامه‌ریزی‌شده پیوند دوره را حفظ می‌کند؛ بازگرداندن کاشت برداشت‌شده ۴۲۲ و حذف/انتقال دورهٔ دارای ارجاع دیگر ۴۰۹ است.
- گام ۷: `GET /operations` با فیلتر، مرتب‌سازی و صفحه‌بندی، و `GET /operations/calendar` با تاریخ مؤثرِ انجام و بازهٔ حداکثر ۶۲ روز اضافه شد.
- آزمون گام ۷: `python django_backend/manage.py test operations`؛ ۳۱ تست روی SQLite حافظه‌ای موفق.
- یادآوری هنگام تغییر عملیات تا گام ۹ ناتمام؛ دیتابیس اصلی/پشتیبان تغییر نکردند و انتقال UUID طرح مستقل می‌خواهد.
- گام بعد: اطلاعات تجمیعی مزرعه و قطعه (گام ۸).
